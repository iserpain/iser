# The Unknown

A responsive, editorial-style landing page for exploring religion, history, sacred texts, and the universe. Built with plain HTML, CSS, and JavaScript—no build step required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Included

- Responsive layout with mobile navigation
- Topic cards with category filters and live search
- Editorial feature, timeline, and approach sections
- Newsletter signup interaction (front-end demo only)

The content is designed to invite exploration without presenting religious traditions as a single hidden truth or treating speculation as fact.
